Numerical lab

Explore the assumptions behind three central calculations. These are analytical teaching models, not measurements of any named AI model.

1. Generating versus selecting a correct answer

Independent candidate success probability p and k attempts give coverage 1 − (1 − p)k. Delivered success also depends on selection quality conditional on a correct candidate existing.

2. Rare correct answers demand precise verification

Acceptance precision = p × true-positive rate / [p × true-positive rate + (1 − p) × false-positive rate]. This threshold model is different from selecting the highest of k scores.

3. Capability horizon depends on required reliability

Use the illustrative logistic model from Lecture 8. The result is human-baseline task duration, not agent runtime. hr = h50 exp[−log(r/(1−r))/β].

Reproduce the calculations

The accompanying Python lab checks numerical examples and boundary cases using only the standard library. It makes no network or model calls.

python numerical_lab.py

Change one assumption at a time. Correlated samples, shifting generator quality, and a verifier selected on the same test set invalidate simple interpretations of these curves.
